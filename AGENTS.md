# Amorri Studio - instructions for AI coding agents

Before editing this repository, **read [`CLAUDE.md`](./CLAUDE.md)** in the repository root and follow its coding principles.

For a new coding session:
1. Inspect the current working tree, active branch, recent commits, and relevant source/tests. Do not assume a previous chat's context is available.
2. Follow `CLAUDE.md`: clarify assumptions, make minimal changes, and verify the specific result.
3. Keep any additional project-specific context in tracked repository files; never record credentials, access tokens, or customers' private data.

This file is an entry point for agents that recognize `AGENTS.md`. `CLAUDE.md` remains the canonical copy of the supplied guidelines.
